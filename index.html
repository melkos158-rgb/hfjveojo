From file to first ride

STEP 01

Find the fit

Filter by your scooter. Each model lists the stem clamp diameter and deck width it was measured on, so you know before you slice.

STEP 02

Modify

Most uploads ship a parametric STEP file next to the STL. Change a bolt spacing, keep the rest, re-export.

STEP 03

Print it right

Makers publish the profile that worked: material, layer height, wall count, infill. Start from theirs instead of guessing.

STEP 04

Report back

Log the print with kilometres ridden. Parts that survive a winter rise; parts that crack get flagged on the file.
